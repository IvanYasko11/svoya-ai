# СВОЯ AI

Личный AI-оператор.

## Текущий этап
V0.3 — технический skeleton.

## Архитектура
User → Operator → Decision Layer → Risk Gate → Tool → Verifier → Result

## Сейчас работает
- UI оператора
- демонстрация 6 стадий
- Risk Gate (demo)

## Ещё не подключено
- реальная LLM
- Web Research
- Laya
- Verification engine

## Принцип
Минимум инфраструктуры, максимум полезного результата. Опасные/необратимые действия — только после явного подтверждения пользователя.
